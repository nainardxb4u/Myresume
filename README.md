# Nainar Mohamed — Resume

Personal resume site built from
[LinkedIn profile](https://www.linkedin.com/in/nainar-mohamed-97159410b).

## Preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8000`.

Use **Print / Save PDF** for a clean A4 export.

## Notes

- Phone and email are intentionally omitted (not fully public on LinkedIn). Add them in `index.html` before circulating the resume.
- Content reflects publicly available LinkedIn experience, education, certifications, and recommendation text.
